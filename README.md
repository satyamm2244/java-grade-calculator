# Java Grade Calculator

A simple console-based Java application that calculates a student's total marks, average, grade, and pass/fail status.

## Features

- Enter student name
- Choose number of subjects
- Enter subject names
- Enter marks for each subject
- Validate marks between 0 and 100
- Calculate total marks
- Calculate average
- Assign grade
- Display pass/fail status
- Show a formatted report card

## Technologies Used

- Java
- Scanner
- Arrays
- Loops
- Conditional Statements

## Grading System

| Average | Grade |
|----------|-------|
| 90 - 100 | A+ |
| 80 - 89 | A |
| 70 - 79 | B |
| 60 - 69 | C |
| 50 - 59 | D |
| Below 50 | F |

## How to Run

Compile the program:

```bash
javac src/GradeCalculator.java
